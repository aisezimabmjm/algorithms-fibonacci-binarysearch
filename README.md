# Практическая работа: Фибоначчи и Бинарный поиск

## 1. Объяснение и визуализация для Фибоначчи (Task 1)

**Как работает алгоритм:**
Рекурсивный Фибоначчи считает число через сложение двух предыдущих: F(n) = F(n-1) + F(n-2). Функция постоянно вызывает саму себя с меньшими аргументами, пока не дойдет до базовых случаев — 0 и 1, которые заданы жестко и останавливают рекурсию.

**Структура вызовов (кто кого вызывает) на примере fibonacci(4):**
1. `fibonacci(4)` запускает два вызова:
   * `fibonacci(3)`
   * `fibonacci(2)`
2. `fibonacci(3)` в свою очередь вызывает:
   * `fibonacci(2)`
   * `fibonacci(1)` -> возвращает **1**
3. `fibonacci(2)` (первый) вызывает:
   * `fibonacci(1)` -> возвращает **1**
   * `fibonacci(0)` -> возвращает **0**
   * Итог для `fibonacci(2)`: 1 + 0 = 1.
4. Второй `fibonacci(2)` точно так же возвращает **1**.
5. Результаты складываются снизу вверх:
   * `fibonacci(3)` = 1 + 1 = 2
   * `fibonacci(4)` = 2 + 1 = 3

2. Итеративный Бинарный Поиск (Task 2)
Как работает алгоритм:
Берем отсортированный массив и две границы: low (начало) и high (конец). На каждом шаге находим середину mid = (low + high) / 2:
Если элемент в середине равен искомому — мы нашли его.
Если элемент в середине меньше искомого — сдвигаем левую границу: low = mid + 1.
Если элемент в середине больше искомого — сдвигаем правую границу: high = mid - 1.
Визуализация на массиве: [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
Пример 1: Поиск числа 23 (есть в массиве)
Итерация 1: Диапазон 0..9. Середина — индекс 4 (16). Так как 16 < 23, ищем справа (low = 5).
Итерация 2: Диапазон 5..9. Середина — индекс 7 (56). Так как 56 > 23, ищем слева (high = 6).
Итерация 3: Диапазон 5..6. Середина — индекс 5 (23). 23 == 23 — найдено на индексе 5.
Пример 2: Поиск числа 2 (в начале массива)
Итерация 1: Диапазон 0..9, середина — 16 (индекс 4). 16 > 2 -> ищем слева (high = 3).
Итерация 2: Диапазон 0..3, середина — 5 (индекс 1). 5 > 2 -> ищем слева (high = 0).
Итерация 3: Диапазон 0..0, середина — 2 (индекс 0). 2 == 2 — найдено на индексе 0.
Пример 3: Поиск числа 50 (нет в массиве)
Итерация 1: 16 (индекс 4) < 50 -> сдвиг вправо (low = 5).
Итерация 2: 56 (индекс 7) > 50 -> сдвиг влево (high = 6).
Итерация 3: 23 (индекс 5) < 50 -> сдвиг вправо (low = 6).
Итерация 4: 38 (индекс 6) < 50 -> сдвиг вправо (low = 7).
Завершение: low (7) > high (6). Цикл остановился, результат -1.
3. Рекурсивный Бинарный Поиск (Task 3)
В чем разница с итеративным:
Логика поиска та же, но вместо цикла while метод перезапускает сам себя с новыми границами:
Если low > high, элементы закончились, возвращаем -1.
Если arr[mid] == target, возвращаем mid.
Иначе вызываем binarySearchRecursive с новыми границами (mid - 1 или mid + 1).
